## Platform

web

## Stack

User-selected React with JavaScript and JSX, Tailwind CSS, and official shadcn/ui components installed through its CLI into `src/components/ui`. Configure shadcn for JavaScript. Node.js with JavaScript for the local backend and worker. Author application code only as `.js` and `.jsx`; no TypeScript application files or TypeScript configuration. Dependency-provided type definitions are permitted.

## Users

One person managing their own local projects, giving Codex tasks, inspecting observable work, reviewing design artifacts, and explicitly approving implementation.

## Product Purpose

Provide one private workspace for direct conversations and assigned tasks with configured Codex roles, observable local project services, and a website workflow: select a project, start services, confirm readiness, capture a page, generate or import a proposed design image, approve its exact revision, implement, and verify in the browser.
