# Elesis delegation and named roster verification

The user chose automatic delegation within the assigned goal and existing permissions. Implementation is JavaScript/JSX and extends the existing local queue, immutable profile snapshots, private artifact handling and single-page interface. Each goal captures the current coordinator and eligible specialist roster in its fixed conversation scope; ordinary chat does not start delegation.

## Scope and limits

Delegation creates 1–6 independent bounded specialist assignments, with up to three active native turns. It is not a recursive task graph or permission grant. Profile/conversation work serializes; native subscription limits still apply and failures require explicit retry. Project editing retains the exact-design-image approval and explicit implementation workflow. Group cancellation does not terminate project services or unrelated agent jobs. The real trial used personal scope; project snapshot isolation and project/personal separation are separately exercised by tests. Firefox evidence shows completed native work; in-flight cancellation and retry interaction checks use labelled synthetic fixtures.
