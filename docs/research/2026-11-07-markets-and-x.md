# Markets and X implementation verification

The owner requested implementation of the supplied prompt, then clarified: choose X accounts later; include charts/watchlists, manual trades and buy/hold/reduce/exit decision support. Work is isolated on `codex/x-crypto-workspace`; no commit, merge, deployment or additional automation was performed.

## Delivered behavior

- Markets and X news are lazy-loaded contexts in the existing single-page workspace. Both use official installed shadcn/ui primitives, preserve the current themes, and hide the project command dock while active. Charts include crosshair OHLC, zoom/reset, visible TradingView attribution, an accessible recent-candle table, source times and calculated closed-candle indicators.
- CoinGecko public USD aggregate data was verified live. Its documented native OHLC intervals are 30 minutes, four hours and four days, with no volume. Close timestamps are converted to open timestamps for charting. Kraken finer-interval USD spot OHLCV remains selectable, but this network returned `UNABLE_TO_VERIFY_LEAF_SIGNATURE` for Kraken. No verification bypass was used; Node's process uses its bundled and already installed system trust roots. Current CoinGecko endpoint access succeeded without a key; provider access/rate policies may change and errors remain visible.
- Manual holdings/buys/sells persist locally. USD weighted-average basis includes fees; unknown opening basis stays unknown until fully closed. Oversells and deletions invalidating historical holdings are rejected. Durable request receipts deduplicate retries, reject conflicting reuse and prevent removed transactions from reappearing on replay. Quotes, cost basis, allocation and P&L remain distinct; absent quotes/basis are not estimated. These records are not exchange orders or a tax ledger.
- One-shot local price rules use deterministic code during explicit quote refresh. They do not promise continuous monitoring while the app/computer is unavailable and do not send Telegram messages.
- Risk profile and asset/portfolio review capture bounded immutable inputs. One explicit native Codex job returns structured assessments, opposing evidence, downside, invalidation and limitations with host-owned source references. Missing evidence is a valid outcome. Available model/effort metadata is loaded without a model turn; GPT-6 Luna/low is preferred when reported available. Overrides are process-local, preserving the global Sol/ultra configuration. Reported token usage is retained when received; none is fabricated. Old input revisions/expired quotes mark saved output stale. Cancellation discards late publication independently of project services.
- X starts with no accounts or paid-read permission. Handles/categories, reply/repost controls, keyword/account/category/date/unread/saved filtering and local post selections persist. The official app bearer is stored in a private 0600 file using no-follow reads and atomic replacement; saving does not call X. Credentials are never returned. Paid-read consent, provider-cap acknowledgement and a positive daily reservation budget are required before an explicit refresh. Three-account batches rotate fairly; lookups/timelines reserve conservative reviewed resource costs before requests. Uncertain calls are not refunded. Rate limits persist backoff; setting/revocation races discard late results. Local reservations are not actual billing or guaranteed X spending caps. No access bypass, scraping or X writes exist.
- Summaries use at most 20 owner-selected fresh cached posts, one requested Codex turn and source attribution. X content is untrusted reference data, not instructions or verified reporting. Expired cached text is hidden. Upstream post deletion is not continuously monitored; the interface explicitly avoids asserting continued availability.
- Newspaper reuse is off by default and cached-only. At most one selected X claim per eligible section replaces a bounded candidate while ordinary-source coverage remains. Fresh cached USD prices can be reused only for the complete BTC/ETH/SOL set; unavailable PHP/change values remain null and mark the edition partial. The existing schedule, model turn, source/story bounds and two A4 renderer remain unchanged.
