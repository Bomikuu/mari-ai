# Elesis and parallel specialist teams

The user wants to give the CEO a goal, let her delegate automatically within its project and permissions, and inspect every specialist's actual work in Mari. Names in portrait order: Elesis, Lire, Arme, Amy, Mari, Rohan, Lass, Zero, Jin, Dio, Ryan, Sieghart. Roles remain separate. Existing historical snapshots stay immutable.

## Execution

A CEO profile has an explicit delegation capability, independent of name/portrait. Its composer adds Delegate goal. Chat and individual assignments remain available. A native structured planning turn selects 1–6 distinct enabled specialist snapshots captured in the goal's exact project/personal scope. The backend independently validates the plan. It creates one chat, task and owned workspace per specialist; no recursive delegation, model-selected paths or expanded authority. The CEO releases its execution slot while specialists run and later synthesizes their completed responses in a native turn. At most three independent agent turns run concurrently in the single leased worker; same-profile and same-chat work serialize. Existing non-agent AI workflows remain exclusive; managed services remain independent.

The team persists its goal, coordinator, members, lifecycle and latest job references. Actual execution records supply status, current action, command, elapsed time, errors, files and outputs. Failed/interrupted stages require explicit retry; completed specialists are preserved. Group cancellation affects only team jobs, never unrelated agent work or project services. Recovery after worker interruption does not replay unfinished turns automatically.

## Interface and identity

The existing matte light/midnight workspace gains a Team view in the CEO chat, with flat named assignment rows and controls to inspect each specialist's chat, cancel the team and retry stopped work. Planning and synthesis are visible phases. There are no fabricated availability indicators. The roster sorts by the requested portrait/name order; a superseded duplicate reviewer is archived reversibly. Profile names are unique, and the profile editor exposes delegation and archive settings. Existing portraits and central avatar/globe remain unchanged.

CEO delegation cannot grant source writes, approve images, change accounts, send messages, install software, publish or stop project services.
